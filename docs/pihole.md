pi# Pihole

## Overview

Pihole is a network-wide ad blocker that acts as a DNS sinkhole, blocking ads and trackers for all devices on your network.

## Key Features

- DNS-level ad blocking
- Web interface for management
- Customizable blocklists

## Configuration

Pihole is configured via the `docker-compose.yml` file. The web interface is available at `https://pihole.home.com`.

## Usage

- Access the web UI at [https://pihole.home.com](https://pihole.home.com)
- Configure blocklists and DNS settings as needed
