# Authentik

## Overview

Authentik is an open-source identity provider focused on flexibility and ease of use. It provides authentication, authorization, and user management for your services.

## Key Features

- Single Sign-On (SSO)
- OAuth2, SAML, and LDAP support
- User and group management

## Configuration

Authentik is deployed with PostgreSQL and Redis backends. The main interface is available at `https://auth.home.com`.

## Usage

- Access the portal at [https://auth.home.com](https://auth.home.com)
- Configure providers, applications, and users as needed
