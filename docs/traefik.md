# Traefik

## Overview

Traefik is a modern reverse proxy and load balancer that makes deploying microservices easy. It automatically discovers services and routes traffic based on configuration and labels.

## Key Features

- Dynamic service discovery
- SSL termination
- Integrated dashboard
- Middleware support

## Configuration

Traefik is configured via the `docker-compose.yml` file and uses labels to route traffic to services. The dashboard is available at `https://traefik.home.com`.

## Usage

- Access the dashboard at [https://traefik.home.com](https://traefik.home.com)
- Manage routes and middlewares via Docker labels
