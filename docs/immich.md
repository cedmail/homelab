# Immich

## Overview

Immich is a self-hosted photo and video backup solution with mobile and web clients.

## Key Features

- Automatic photo and video backup
- AI-powered search and tagging
- Multi-user support

## Configuration

Immich is deployed with PostgreSQL and Redis backends. The web interface is available at `https://photos.home.com`.

## Usage

- Access Immich at [https://photos.home.com](https://photos.home.com)
- Use mobile apps for automatic uploads
